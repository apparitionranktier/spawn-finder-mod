## 📖 About

Spawn Finder locates the exact world spawn point and displays the spawn radius overlay so you can build spawn-proof platforms or optimize spawn farms.

---

## ✨ Features
<a name="features"></a>

- **Exact Spawn Point** — shows world spawn XYZ to the block.
- **Spawn Radius Overlay** — visualises the 20-block radius in the world.
- **Respawn Anchor Tracker** — tracks anchor positions in the Nether.
- **Bed Spawn Log** — logs all set bed spawn locations.
- **Spawn-Proof Checker** — highlights blocks where mobs can spawn.
- **Map Export** — saves spawn zones to an image.

> 🔑 **100% free** — no key system, no linkvertise, no ads.
